Decode Launcher portable mode

While this file sits next to decode-launcher.exe, Decode Launcher keeps its settings, its
download cache and its record of installed apps in the DecodeLauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move Decode Launcher with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Decode Launcher) instead.
If DecodeLauncherData can't be written (for example on a read-only drive), Decode Launcher says
so and uses %APPDATA%\Decode Launcher instead.
