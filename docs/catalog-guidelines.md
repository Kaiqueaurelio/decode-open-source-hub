# Diretrizes do catálogo

## Critérios de entrada

Um programa só deve ser descrito como open source quando houver evidência confiável de uma licença que disponibilize o código-fonte e conceda direitos de uso, estudo, modificação e redistribuição nos termos dessa licença.

A ficha deve apontar para uma fonte oficial. Priorize a página de licença do projeto; se ela não existir, use o repositório oficial e registre a incerteza em vez de adivinhar.

## Campos obrigatórios

- Identificador único (slug).
- Nome do produto.
- Categoria.
- Descrição curta e objetiva em português.
- Plataformas confirmadas.
- Licença declarada.
- Site oficial.
- Código-fonte ou página oficial de origem.
- Página oficial de download ou instalação.
- Tags de pesquisa.

Consulte data/schema.json para o formato esperado.

## Linguagem editorial

- Descreva recursos concretos e evite superlativos publicitários.
- Não prometa que um software é seguro, perfeito, atualizado ou compatível sem evidência.
- Não confunda gratuito, freemium, source-available e open source.
- Não copie parágrafos extensos de páginas de terceiros.
- Use emojis como marcadores visuais provisórios; não use logotipos de terceiros sem permissão.
- Identifique edição e limitações de licença quando isso for relevante (por exemplo, Community Edition).

## Links

Todos os links do catálogo devem usar HTTPS. O site, o código-fonte e o download devem direcionar para fontes oficiais do projeto sempre que possível. Se um link oficial não estiver disponível, justifique a exceção em revisão e use uma fonte confiável identificada.

Não crie URLs para arquivos de instaladores por suposição. Prefira a página oficial de downloads, onde o usuário pode escolher sua plataforma e a versão atual.

## Categorias

Use uma categoria existente sempre que se encaixar. Adicione uma nova categoria apenas quando houver uma área de uso distinta que não seja bem coberta pelas atuais.

Categorias iniciais:
- Criação visual
- Produtividade
- Internet e comunicação
- Segurança e privacidade
- Utilitários
- Infraestrutura e nuvem
- Vídeo e áudio
- CAD e engenharia
- Desenvolvimento
- Ciência e dados

## Atualização

Confira páginas de licença e links oficiais periodicamente e sempre que uma contribuição alterar esses campos. Registre no pull request quais fontes foram consultadas. Não afirme que todo o catálogo foi verificado em tempo real se isso não aconteceu.
