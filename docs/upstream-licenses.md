# Referências, licenças e atribuição upstream

O Decode Open Source Hub mantém sua própria licença MIT para o código e CC BY 4.0 para os textos/dados editoriais originais (consulte `LICENSE` e `LICENSE-DATA.md`).

O ArtCraft Launcher é um projeto separado: https://github.com/storytold/craft-launcher. O upstream declara MIT OR Apache-2.0 para o código e disponibiliza `LICENSE-MIT`, `LICENSE-APACHE`, `NOTICE` e `ATTRIBUTION.md`.

Este catálogo não copia o código-fonte, screenshots, ícones ou logotipos do launcher. A ficha em [docs/artcraft-launcher.md](docs/artcraft-launcher.md) é uma síntese descritiva e inclui links para a documentação de origem. Nomes e marcas permanecem com seus titulares.

Antes de redistribuir código ou ativos de terceiros, leia os avisos e os termos oficiais. O README upstream informa expressamente que a marca e os logotipos ArtCraft não estão cobertos pelas licenças de código aberto.
