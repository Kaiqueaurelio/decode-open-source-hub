03 / PRINCÍPIOS DE ENGENHARIA

Compartilhado por todos os softwares

Construído do jeito difícil.

Cada aplicativo da suíte Decode é escrito do zero em Rust puro e obedece aos mesmos padrões rigorosos de performance nativa, transparência de código e privacidade.

  • 01

    Código Aberto

    Cada linha de código está no GitHub sob licenças permissivas (MIT ou Apache-2.0). Leia, estude, faça fork e crie em cima de uma base sólida e auditável.

  • 02

    Nativo em Rust, Sem Electron

    Compilado diretamente para código de máquina para macOS, Windows e Linux. Aceleração por GPU direta via WGPU e egui. Sem Chromium, sem navegadores embutidos consumindo gigabytes de memória.

  • 03

    Familiar desde o Primeiro Dia

    Layouts, caixas de ferramentas, painéis de camadas e atalhos de teclado que profissionais criativos já utilizam no seu fluxo diário, eliminando curvas artificiais de reaprendizado.

  • 04

    Seus Arquivos, Sua Máquina

    Arquitetura local-first. Trabalhe com arquivos nos formatos padrão do mercado sem depender de conexões com servidores na nuvem, logins forçados ou rastreamento invasivo de telemetria.

  • 05

    Pronto para Agentes & IA

    Controle qualquer ferramenta da suíte via interface de linha de comando (CLI), canais de eventos JSON estruturados ou servidores MCP (Model Context Protocol), prontos para automações com agentes de IA.

  • 06

    Também no seu Navegador

    DecodePhoto, DecodeVector, DecodeLight, DecodePdf, DecodeFig, DecodeWord, DecodeCAD e outros compilam diretamente para WebAssembly (WASM), permitindo execução instantânea no navegador sem downloads.
