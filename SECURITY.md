# Política de segurança

## Escopo

Esta política cobre o código, os arquivos de configuração, os workflows e os dados mantidos diretamente no Decode Open Source Hub.

O catálogo é uma aplicação estática: ele não hospeda instaladores e não autentica usuários. Os softwares de terceiros listados possuem seus próprios processos de segurança e divulgação de vulnerabilidades.

## Reportar uma vulnerabilidade

**Não publique detalhes exploráveis em uma issue pública.**

Use a página de avisos de segurança do GitHub, se estiver habilitada para este repositório:

https://github.com/Kaiqueaurelio/decode-open-source-hub/security/advisories/new

Se o recurso não estiver disponível, abra uma issue solicitando um canal privado, sem incluir publicamente tokens, dados sensíveis ou instruções de exploração. Compartilhe detalhes técnicos apenas por um meio privado confirmado pelos mantenedores.

Inclua, quando possível, o impacto, os passos para reproduzir, a versão ou commit afetado e uma sugestão de mitigação. Não envie credenciais reais ou dados pessoais.

## Cuidados com downloads externos

O Hub aponta para fontes de terceiros. Um link aparecer no catálogo não constitui auditoria de segurança nem garantia de que um instalador seja seguro. Antes de instalar software, confira o domínio, a assinatura ou hash publicado pelo projeto, quando disponível, e as instruções oficiais.

## Resposta

Os mantenedores deverão confirmar o recebimento, avaliar a gravidade, corrigir o problema quando aplicável e publicar informações após existir uma correção ou mitigação adequada. Não é prometido um prazo de resposta fixo neste estágio do projeto.
