## Sobre o Aplicativo

O Decode Effect é o aplicativo de motion design da suíte Decode. Trabalha com animação baseada em nós, keyframing, partículas, simulações procedurais e composição visual para cinema e transmissões.

O **DecodeEffect** foi desenvolvido com foco em desempenho nativo, arquitetura limpa em Rust e segurança de memória. Integrado ao ecossistema [Decode Open Source Hub](https://github.com/Kaiqueaurelio/decode-open-source-hub), o programa pode ser instalado e atualizado de forma centralizada pelo [Decode Launcher](../../launcher/).

## Compilação e Execução Local

Requer o compilador Rust estável instalado (`rustup`):

```bash
# Compilar e executar a aplicação em modo release
cargo run --release -p effectcraft

# Executar a suíte de testes
cargo test --workspace
```

## Instalação pelo Decode Launcher

Para instalar o **Decode Effect** e todos os aplicativos da suíte Decode com instalador gráfico e atualizações automáticas:
1. Abra o [Decode Launcher](../../launcher/).
2. Localize o **DecodeEffect** na grade de aplicativos.
3. Clique em **Instalar** para configurar o binário no seu sistema operacional (Linux, Windows ou macOS).
